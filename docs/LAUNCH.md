## 3-1 名前を決める

ルール：名前・アイコン・ドメインに「Wikipedia」やロゴは使わない。

| 候補 | よいところ | 気になるところ |
|---|---|---|
| **ウィキで6歩**（今の名前）【おすすめ】 | 何をするゲームかが名前だけで分かる。ハッシュタグ `#ウィキで6歩` もすでにゲームに入っている | 「ウィキ」は一般的な言葉なので問題ないが、似た名前のサイトがないか一度検索しておく |
| 6歩でとどけ | 応援したくなる響き。ゲームらしい | 何のゲームか名前だけでは分からない |
| リンク6歩 | 短い。ルールそのまま | 少しかたい |
| たどって6歩 | やさしい響き | 検索で埋もれやすい |

名前を変える場合に直す所：`index.html` の `<title>`・ロゴ・OGP の文・シェア文のハッシュタグ、`ogp.png`（作り直し）。

## 3-2 告知文（X）

どれも、**動画（下の録画）を付けて**投稿するのがおすすめ。動画が付いた投稿は、文字だけより目に止まりやすい。
URL を入れると、ゲームの画像つきカード（OGP）が出る。

### 案A：問いかけ型【おすすめ】

```
「たこ焼き」から「ブラックホール」まで、
ウィキペディアのリンクを6回たどるだけで行けると思う？

毎日1問、みんな同じお題に挑戦するゲームを作りました🎯
無料・登録なし・スマホで遊べます

#ウィキで6歩
https://shu4075.github.io/wiki6/
```

### 案B：作りました型

```
ウィキペディアの青いリンクだけをたどって、
6歩以内にゴールの記事を目指すゲームを作りました！

今日のお題：レオナルド・ダ・ヴィンチ ➜ 忍者

何歩で行けたか、ネタバレなしでシェアできます
#ウィキで6歩
https://shu4075.github.io/wiki6/
```

### 案C：自分の結果を貼る型（2日目以降に）

ゲームの「𝕏 でポストする」で自分の結果を投稿し、その返信に案Aの文と URL を付ける。
「この記号なに？」と気になった人が、返信から遊びに来る形。

### 投稿のコツ

- **夜（21〜23時ごろ）に投稿**：スマホを見ている人が多い時間
- **投稿したらプロフィールに固定**する
- 最初の1時間は、来た返信にすぐ反応する（反応がある投稿ほど広がりやすい）
- 毎日、自分の結果を「𝕏 でポストする」で投稿すると、続けて見てくれる人が増える
- ゲームのURLを貼ると表示が少し減ることがあるので、**URLは返信に貼る**のも手（案C）

## 3-2 画面録画の台本（5〜10秒）

**最初の3秒で「何をするゲームか」が分かること**が一番大事。

| 秒 | 画面 | 文字（動画に重ねる） |
|---|---|---|
| 0〜3 | トップ画面。今日のお題「たこ焼き ➜ ブラックホール」が見える | 「たこ焼き」から「ブラックホール」へ<br>リンク6回で行ける？ |
| 3〜8 | 記事の青いリンクをテンポよくタップ（3〜4回）。上の歩数バーが進むのが見える | 1歩…2歩…3歩… |
| 8〜10 | 「たどり着いた！」と結果の 🟦🟦🟩⬜⬜⬜ | 毎日1問。あなたは何歩？ |

### 撮り方（スマホ）

1. iPhone：コントロールセンターの「画面収録」／Android：クイック設定の「スクリーンレコード」
2. 「おまかせ」や挑戦状機能で、**一度遊んで道を知っているお題**を使うと、迷わずテンポよく撮れる
   - 例：「両利き ➜ ヴォルフガング・アマデウス・モーツァルト」は「モーツァルト」のリンク1つでゴールできる（挑戦状で作れる）
   - 3〜4歩でゴールできる道を先に見つけておくと、見ていて気持ちいい
3. 「進む？」の確認が毎回出るとテンポが落ちるので、撮る前にトップの「くわしいルール」の中で確認をオフにする
4. 撮ったあと、写真アプリで前後を切り、X の動画編集やCapCutなどで文字を重ねる
5. 横幅いっぱいの縦動画のままでOK

## 3-3 感想を集める

- ゲームのトップと結果画面に「💬 感想を送る」ボタンを付けた。押すと X の投稿画面が「#ウィキで6歩 への感想」入りで開く
- 結果画面から送ると、お題の名前も自動で入る（どのお題が難しすぎたか分かる）
- **集め方**：X で `#ウィキで6歩 感想` を検索する。結果のシェアも `#ウィキで6歩` で見られる
- 集まった感想は、Claude Code に貼り付けて「直して」と伝えればよい
  - 難しすぎるお題 → `PAIRS` から外す／差し替える
  - 表示の崩れ → 記事名を伝えてもらえれば、その記事で確認して直す

## 1. 概要

「Wikipediaは6回リンクをたどれば、どの記事にも行ける」という話をそのままゲームにした、スマホ向けのWebゲーム。

- スタートの記事から、本物の日本語版Wikipediaの**青いリンクだけ**をたどってゴールの記事を目指す
- 使えるのは**6歩（6回のリンク）まで**。6歩でゴールに着かなければ失敗
- 毎日全員同じ「今日のお題」があり、結果を絵文字でネタバレなしにシェアできる（Wordle方式）
- 形態：1ファイルのHTML（フレームワークなし）。GitHub Pagesで公開する
- 公開予定URL：`https://shu4075.github.io/wiki6/`

## 2. 目的とターゲット

- **目的**：Xでシェアされて広まる、手軽なスマホゲームを作る
- **ターゲット**：スマホでサクッと遊びたい人。雑学が好きな人。友だちと競いたい人
- **よく似たゲームとの違い**：英語圏には「Wiki Game」「Wikirace」など同じ遊びのゲームが多数ある。このゲームは次の4つで差をつける
  1. **6歩縛り**（歩数に上限があり、失敗がある）
  2. **日本語の変なお題**（例：たこ焼き → ブラックホール）
  3. **スマホで遊びやすい**（リンク検索、押し間違い防止の確認）
  4. **挑戦状**（友だちにお題をURLで送れる）

## 3. 現状（試作版でできていること）

ファイル：`wiki6/index.html`（約660行。HTML・CSS・JavaScriptが1つのファイルに入っている）

| 機能 | 内容 |
|---|---|
| 今日のお題 | 日付（日本時間）でお題が決まる。2026-11-09 が #1。1日1回だけ挑戦でき、結果はlocalStorageに保存 |
| おまかせ | `PAIRS`（32組）からランダムに出題 |
| ランダム | Wikipediaのランダム記事2つ。激ムズ |
| 挑戦状 | スタートとゴールを入力すると `?s=〇〇&g=〇〇` 付きのURLができる。そのURLを開くと「挑戦状がとどいています」と表示 |
| 記事表示 | Wikipedia APIで本文を取得し、記事へのリンクだけを押せるようにする。画像・カテゴリ・外部リンク・赤リンク・注釈は押せない |
| 6歩の管理 | 上部のバーで残り歩数を表示。「1歩もどる」も1歩使う。通ってきた記事は上部に横並びで表示 |
| 進む前の確認 | リンクを押すと「この記事へ進む？のこり◯歩」と確認する（押し間違い防止） |
| リンクをさがす | 記事中のリンクを一覧にして、言葉で絞り込める |
| ゴールの説明 | ゴール記事の冒頭3文と画像を表示（🎯ボタンでいつでも見られる） |
| 結果 | 歩数・時間・称号（1歩「奇跡の1歩」〜6歩「ギリギリセーフ」）・ルート表示・シェア文 |
| シェア | ネタバレなし（`🟦🟦🟦🟩⬜⬜`）とルートつきの2種類。スマホでは `navigator.share`、PCではコピー |
| 転送ページ | 「天文」→「天文学」のような転送は、転送先の正式名で判定する |
| 出典表示 | 各記事の下に出典（CC BY-SA 4.0）とWikipediaへのリンク。トップに非公式表記 |
| エラー表示 | 通信できないとき、記事が見つからないときにメッセージを出す |

**確認済み**：Wikipedia APIの代わりにテスト用のデータを返す形で、ゴール・6歩で失敗・もどる・リンク検索・転送・存在しない記事のエラーが正しく動くことを確認した（Playwright、iPhone相当の画面サイズ）。

**未確認**：本物のWikipediaにつないだ動作。作成環境から外部に通信できなかったため、**一度も本物の記事で遊んでいない**。Phase 1 で最優先に確認する。

## 4. 技術構成

| 項目 | 採用 | メモ |
|---|---|---|
| 言語 | HTML / CSS / JavaScript（フレームワークなし） | しゅうが中身を理解しながら直せるようにする |
| 記事データ | 日本語版Wikipedia API `https://ja.wikipedia.org/w/api.php` | `origin=*` を付けるとブラウザから直接呼べる（CORS）。APIキー不要 |
| 本文 | `action=parse&prop=text&redirects=1` | 返ってきたHTMLから、不要な部分を消してリンクを差し替える（`renderArticle`） |
| 記事名・説明 | `action=query&prop=extracts\|pageimages&redirects=1` | 転送を解決した正式名、冒頭3文、画像（`getInfo`） |
| ランダム | `action=query&list=random&rnnamespace=0` | |
| 保存 | localStorage（キー `wiki6-daily-<番号>`） | try/catchで囲んである |
| フォント | Google Fonts「Zen Maru Gothic」（見出し・ボタン） | |
| 公開 | GitHub Pages | 無料、最初からhttps |

**主な関数（index.html の script 内）**

- `api` / `getInfo` / `getPage` / `randomTitles`：Wikipedia API との通信
- `startGame` → `loadPage` → `renderArticle`：ゲーム開始と記事表示
- `askGo` → `go` → `checkEnd` → `finish` → `renderResult`：1歩進む流れと結果表示
- `todayNo` / `dailyPair`：今日のお題の番号とお題（`PAIRS[(i * 7) % PAIRS.length]` で並びを混ぜている）
- `NS_BLOCK`：押せないページ（ファイル、Category、Wikipedia:、Help: など）の判定

## 6. ルール（必ず守る）

- 記事の文章は Wikipedia のもの（**CC BY-SA 4.0**）。各記事の出典表示と、トップの「非公式のファン作品で、ウィキメディア財団とは関係ありません」を消さない
- ゲーム名・アイコン・ドメインに「Wikipedia」やWikipediaのロゴを使わない
- Wikipedia API に負担をかけない。**記事を一括でダウンロードして保存しない**。プレイ中に1歩ごとに1回読み込む今の形を守る。チェック用スクリプトは間隔をあけて呼ぶ
- 当面は広告を入れない
- しゅうは**プログラミングの経験が浅い**。コードを丸投げせず、変更のたびに「何を・なぜ変えたか」を短く説明する。新しいライブラリやビルドの仕組み（npm でのビルドなど）は、必要になるまで入れない（チェック用スクリプトは例外）
- **1項目ずつコミットする**。気に入らない変更はその項目だけ元に戻せるようにする
- 変更したら、テスト用データ（Playwright で API の代わりにテスト用の返事を返す方法）か本物のWikipediaで、少なくとも「ゴール」「6歩で失敗」が動くことを確認してから報告する
